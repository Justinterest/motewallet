# 管理后台页面设计文档

## 全局布局

### 侧边栏导航（Sidebar）
- 宽度：256px，固定左侧
- 顶部：Motewallet Admin Logo
- 菜单项（带图标）：
  - Dashboard（仪表盘图标）
  - Merchants（用户组图标）
  - Fee Templates（标签图标）
  - **Withdrawal Reviews（盾牌图标）** — 待审核数量 Badge
  - Transactions（列表图标）
  - System Settings（齿轮图标）
  - Admin Users（用户图标）
  - Audit Logs（文件图标）
  - Webhook Logs（闪电图标）
- 底部：管理员名称 + 角色 + 登出按钮
- 当前菜单高亮：左侧蓝色竖线 + 蓝色背景

### 主内容区域
- 左 padding 256px（侧边栏宽度）
- 顶部 Header：页面标题 + 面包屑
- 内容 padding：32px
- 背景色：`#F1F5F9`

### 商户列表

1. **操作栏**
   - 搜索框（邮箱 / 商户 ID）
   - 筛选：KYC 状态、手续费模板

2. **商户表格**
   - 列：
     - 商户 ID
     - 邮箱
     - KUN 子商户号

     - 操作（查看详情 / 冻结/解冻）

### 商户详情 `/admin/merchants/:id`

1. **基本信息卡片**
   - 商户 ID、邮箱、KUN 子商户号

   - 注册时间
   - 手续费模板（可修改，下拉选择）
   - 操作按钮：冻结/解冻

2. **账户余额卡片**
   - 资金账户余额列表（各币种）
   - 交易账户余额列表（各币种）

右列（40%）：

3. **操作时间线**
   - 注册 → 签署协议 → 提交 KYC → KYC 通过/失败
   - 每步显示时间

4. **交易统计卡片**
   - 总充值 / 总提现 / 总兑换
   - 平台手续费收入合计

下方全宽：

5. **交易记录 Tab**
   - Tab 切换：充值 / 兑换 / 提现 / 划转 / 全部
   - 表格同 P-14 格式

## A-04: 手续费模板管理 `/admin/fee-templates`

### 模板列表

1. **操作栏**
   - "创建新模板" 按钮
   - 搜索框

2. **模板卡片网格**（或表格）
   - 每个模板卡片：
     - 模板名称（默认模板有 ⭐ 标记）
     - 描述
     - 绑定商户数量
     - 创建/更新时间
     - 操作：编辑 / 删除 / 设为默认

### 模板编辑 `/admin/fee-templates/:id`

Tab 切换三类费率：

**Tab 1: 兑换手续费**
- 表格形式：
  - 列：币对（From→To）、费率（%）、最低手续费
  - 每行可编辑
  - 支持添加/删除行
- 预设币对：USDT/USD, USD/USDT, USDT/HKD, HKD/USDT, USDT/EUR, USDT/USDC, USDC/USDT, USDT/BTC, BTC/USDT

**Tab 2: 数币提现手续费**
- 表格形式：
  - 列：币种、链类型、费率（%）、固定费用
  - 每行可编辑
- 预设：
  - USDT: ETH_ERC20, TRX_TRC20, SOL_Solana, BSC_BEP20
  - USDC: ETH_ERC20, TRX_TRC20
  - BTC: -

**Tab 3: 法币提现手续费**
- 表格形式：
  - 列：币种、转账类型、费率（%）、固定费用
  - 每行可编辑
- 预设：
  - USD: LOCAL, TT
  - HKD: LOCAL, CHATS, TT
  - EUR: LOCAL, TT

底部：
- 费用计算公式说明：`手续费 = max(固定费用, 交易金额 × 费率)`
- "保存" 按钮 + "取消" 按钮
- 保存时显示影响的商户数量确认

## A-06: 系统配置 `/admin/settings`

### Tab 布局

**Tab 1: KUN API 配置**
- API Base URL
- API Key（脱敏显示）
- API Secret（脱敏显示）
- KUN 公钥（用于 Webhook 验签）
- Webhook 回调 URL
- "测试连接" 按钮
- 连接状态指示

**Tab 2: 币种与链配置**
- 支持的数字货币（开关控制）：USDT ✓ / USDC ✓ / BTC ✓
- 支持的法币：USD ✓ / HKD ✓ / EUR ✓
- 支持的链类型（每个币种独立配置开关）

**Tab 3: 默认手续费模板**
- 当前默认模板名称 + 链接跳转到模板详情
- 修改默认模板（下拉选择）

**Tab 4: 系统公告**
- 公告列表 + 新增公告
- 每条公告：标题、内容、发布时间、状态（已发布/草稿）

## A-10: 提现审核 `/admin/withdrawal-reviews`

### 布局

1. **统计摘要卡片行**（3 列）
   - 待审核数量（红色高亮）
   - 今日已审核数量
   - 今日拒绝数量

2. **筛选栏**
   - 提现类型（All / 数币提现 / 法币提现）
   - 币种筛选
   - 金额范围
   - 商户搜索
   - 时间范围

3. **待审核列表表格**
   - 列：
     - 勾选框（批量操作）
     - 平台订单号
     - 商户（邮箱）
     - 提现类型（徽章：数币 / 法币）
     - 金额 + 币种
     - 平台手续费
     - 目标信息（数币：链+截断地址 / 法币：银行名+截断账号）
     - 提交时间
     - 操作（通过 / 拒绝 / 查看详情）
   - 金额按降序排列（大额在前，优先审核）
   - 分页器

4. **批量操作栏**（勾选后出现）
   - "批量通过" 按钮
   - 已选 N 笔，合计金额 XXX

5. **审核确认模态框**

   **通过确认：**
   - 订单摘要（商户、金额、目标地址/账户）
   - 备注输入（可选）
   - "确认通过" 按钮（蓝色主按钮）
   - 批量通过时显示所有订单列表

   **拒绝确认：**
   - 订单摘要
   - 拒绝原因输入（**必填**）
   - 预设拒绝原因快捷选择：
     - "地址风险：目标地址存在安全风险"
     - "金额异常：提现金额异常，请联系客服"
     - "信息不符：提现信息与账户信息不匹配"
     - 自定义输入
   - "确认拒绝" 按钮（红色危险按钮）
   - 提示文案："拒绝后冻结金额将立即解冻至商户可用余额"

6. **审核详情侧边抽屉**（点击查看详情触发）
   - 订单完整信息
   - 商户基本信息（邮箱、注册时间、KYC 状态）
   - 商户近 30 天提现统计（笔数 / 总金额）
   - 目标地址/银行账户完整信息
   - 操作按钮：通过 / 拒绝

### 权限

- `SUPER_ADMIN` / `OPERATOR`：可查看、可审核
- `FINANCE`：仅可查看，审核按钮灰显

### 交互

- 新待审核订单进入时，页面自动刷新或顶部出现提示条
- 审核操作后，该行从列表移除并显示成功 Toast
- 如果其他管理员已审核同一订单，提交时提示"该订单已被处理"
